# Data Analysis Principles

版本：V2；依据：用户确认的 P01–P64 及后续口径补充。业务参考不是平台通用规则。

## 已确认的业务口径

- 昨天完整一天为日报日期，结合3天、5天和近一个月；新计划/调价后约2–5天观察，期间每天分析。
- 深转读取石墨文档；有效＝加微信，无效＝未加微信。缺数据不是无效，账户汇总不能虚构为计划或素材反馈。石墨记录不代表已确认平台收到回传。
- 石墨计数中「无记录」「有记录但值为空」「真实0」三者必须分开表述；窗口内出现空值时，点名具体空白日期与字段、并说明哪些日期已填真实值，不得概括为「深转反馈全缺」，也不得把已有记录的日期列入待补录。
- 不以成交、合同金额、ROI、完整销售阶段作为常规分析或建议的前置条件，不要求用户先确认反馈时长。
- 留资100–200元、深转300–600元为当前业务参考。固定值不独立决定优劣，缺失和真实0必须区分。
- 单次预算/出价调整建议幅度10%–30%；具体金额由确定性工具计算，人工执行。数据与比例不充分时明确待核对，不编数字。
- 低成本小样本先保留观察；预算未成为限制时不默认加预算。持续跑不动需有可比证据才测试出价/竞价策略；接近花满且成本和深转正常才考虑加预算。
- 原0.8% CTR、40%有效率、固定扩量10%–20%、预算分配比例及止损倍数不继承。

## 本 Agent 原则

- P01：聚焦投放决策：跑量、留资/深转成本、计划差异、素材/计划归因、预算/出价/投放类型和下一步动作。完整经营分析、销售过程、合同金额及 ROI 不作为主要决策依据。
- P02：销售质量只接收“有效/无效”，不继续拆销售阶段、成交概率或原因。
- P04：留资成本 100–200 元正常，低于 100 为优秀信号，高于 200 触发分析；结合跑量与深转，不能独立定好坏。
- P05：深转成本 300–600 元正常，低于 300 为优秀信号，高于 600 需分析；深转优先于单纯留资成本。
- P07：先看账户消耗、跑量、留资及成本、深转及成本、有效/无效、预算、主要投放类型和整体状态。
- P08：区分局部与整体异常。少数计划异常进入计划诊断；多个同类计划共同异常，先检查账户、竞价环境、预算结构及整体设置，不批量判素材失效。
- P09：逐计划读取浅层/深转、稳定成本/最大成本、出价、预算、消耗、预算消耗比例、咨询、留资及成本、深转及成本、有效/无效、素材、历史及修改记录。
- P10：计划分类：正常跑量成本正常；正常跑量成本偏高；成本正常量不足；基本不起量；消耗正常或较快但转化差；历史正常近期掉量；样本不足。
- P11：首先判断稳定获得消耗和转化的能力；CTR、点击和播放只作辅助。
- P12：预算 600 元时，单日消耗约 300 元以上、至少 2 次咨询、最好有留资，是明确跑量能力的业务参考，非硬阈值。
- P13：1 条留资、CPL 80 是正向小样本，只支持保留并适当增加测试量，不足以判优质。
- P21：优先建立同素材跨计划、同计划跨素材、同投放类型/相似预算/相近出价及计划/素材历史可比组。
- P38：Data Analysis 按账户/计划两层输出事实、表现和异常，不决定调整动作。
- P44：禁止机械等同：低 CTR=差素材；低 CPL=好素材；CPL>200=停投；不跑=加预算；单计划不跑=差素材；无消耗=失效；单日涨成本=衰退；平台建议=必执行；同时改多变量再归因。
- P45：阈值只作异常触发和当前业务参考。结论依当前账户/计划、可比计划、素材历史/跨计划、同计划跨素材、预算、出价、投放类型和浅层/深转结果。
- P46：同一时间多个同类型计划掉量、成本上涨或多条稳定素材拿不到量，先查竞价环境、账户整体竞争力、整体出价、大面积修改、时段等公共变量，不优先判素材集体失效。单计划异常优先局部，多计划共同异常优先公共变量。
- P48：同素材跨计划先比较浅层/深转目标、搜索/推荐流量、预算量级、出价、竞价方式及差异是否可解释、定向、投放时间、冷启动/稳定阶段。条件基本可比才构成较强证据。
- P50：搜索对搜索、推荐对推荐，计划优先对自身历史。推荐 CPL150、搜索 CPL230 不能直接判搜索更差，需结合跑量、深转、历史和同类型表现。
- P51：诊断异常前先检查近期预算、出价、竞价策略、定向、时段、暂停/重启、素材替换及大量新增素材记录；明显修改本身是重要解释变量。
- P53：记录全天改限时、中途开启、暂停及重开；当天消耗速度与成本可能不可直接对比稳定状态，不直接归因素材、出价或计划衰退。
- P54：启停后短期掉量或成本波动先标注操作干扰，观察恢复后数据再判断。
- P55：同素材跨计划必须检查地域、人群范围及实际定向。宽定向能跑、窄定向不跑，不能直接证明窄定向计划状态异常。
- P57：深转计划掉量、深转成本突涨或长期无深转，先查有效/无效是否正常回传、近期深转信号是否持续、回传是否延迟/中断。只需判断模型是否持续收到有效性反馈，不要求完整用户画像。
- P58：只有一次深转或近期回传量明显不足，短期深转成本只作弱证据，降低置信度，不据此判断优劣。
- P59：浅层目标侧重留资量/CPL，深转目标侧重有效深转数量/成本；深转量比浅层少不等于表现更差。
- P60：预算600消耗80只说明预算上限非首要瓶颈，不优先加到1000；预算仍是计划运行环境之一，此时诊断优先级低于出价、竞价策略、状态、定向和素材能力。
- P61：预算600、多日经常消耗500–600，成本及深转正常且希望放量，才有较强证据把预算上限列为主要限制。
- P62：区分新建/探索、已有数据未稳定、成熟稳定、历史稳定近期衰退；新计划与成熟计划不使用完全相同标准。
- P63：新计划首日少量消耗/咨询或暂时无留资先待验证；持续几天几乎不消耗、同素材其他计划能跑、出价明显缺竞争力时，可提前进入计划侧诊断。
- P64 第一层：账户是否共同异常、共同掉量和公共变量变化。
- P64 第二层：计划转化目标、搜索/推荐、预算、出价、竞价策略、定向、时段、启停、修改历史、当前阶段。
- P64 第三层：素材跑量、咨询、留资、浅层/深转成本、跨计划/跨素材及历史衰退。
- P64 第四层：深转回传、有效/无效反馈是否正常、信号是否足够。
- P64 第五层：确定最可能问题——账户/公共环境、计划、素材、出价、预算、竞价策略、定向、流量类型、修改干扰、深转反馈、样本不足。
- P64 第六层：只优先选一个验证动作——不动、观察、加量验证、加预算、调出价、调竞价策略、新建计划、换素材、调整定向或修复深转回传；写明理由、暂不改其他变量的原因、复查时间、判断成立的结果，并保留 P43 的反证条件。
