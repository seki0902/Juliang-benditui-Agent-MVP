# 浏览器自动下载与文件导入实施说明

> 更新时间：2026-09-15  
> 当前主路线：浏览器只读下载 + 本地导入分析  
> API：暂不作为主链路，后续有权限时再接

## 1. 当前目标

技术方案的目标是每天自动完成：

1. 使用已登录的本地推浏览器页面下载昨日的单元/计划报表和视频/素材报表；
2. 保存原始文件，校验文件、统计日期和数据完整性；
3. 自动识别报表类型、标准化字段并完成账户/计划/素材对账；
4. 读取可选的石墨反馈文件，计算有效留资量和对接数量；
5. 生成昨日数据、本月累计、异常和调整建议。

计划、预算、出价和素材的实际修改由运营人员手动完成，系统只提供建议并记录执行反馈。

## 2. 系统边界

```text
浏览器自动下载
    ↓
原始文件保存
    ↓
文件识别与字段标准化
    ↓
指标计算与数据对账
    ↓
历史状态、基线和异常检测
    ↓
日报与调整建议
    ↓
运营人员手动执行
    ↓
记录执行结果，进入下一次诊断
```

系统不执行以下平台写操作：

- 暂停或开启计划；
- 修改预算或出价；
- 删除、发布或替换素材；
- 修改抖音来客线索标签。

浏览器脚本也只允许进入报表页面、选择日期和下载文件。遇到登录失效、验证码、短信验证或异常安全提示时停止，等待人工处理，不绕过验证。

## 4. 输入文件

浏览器脚本每次下载：

1. 单元/计划投放明细；
2. 视频/素材数据；
3. 石墨线索反馈（可选）。

平台报表日期范围建议选择“当月 1 日至昨日”，这样可以同时计算本月累计和近期趋势。项目按表头识别文件，不依赖文件名，不要求手工改列名。

平台输入至少需要：

```text
日期、对象 ID、对象名称、消耗、展示次数、点击次数、线索留资数
```

如果能取得，还应保留：

```text
投放类型、私信意向数、计划状态、预算、出价、频次
```

石墨反馈至少需要：

```text
lead_id、lead_date、是否有效、是否对接
```

## 5. 每日运行流程

```text
09:00 启动浏览器下载脚本
  ↓
确认使用昨日日期
  ↓
下载单元/计划报表和视频/素材报表
  ↓
校验下载完成、文件大小和统计日期
  ↓
运行 run_import.py
  ↓
生成昨日数据、本月累计和诊断建议
  ↓
保存 Markdown/JSON/标准化 CSV
  ↓
等待运营人员手动执行调整
  ↓
记录实际执行动作和结果
```

重复运行必须幂等：同一统计日期的同一输入应覆盖或复用已有结果，不重复累计消耗、留资或建议。

## 6. 日报必须包含

### 昨日数据

消耗、平台留资量、单个留资成本、有效留资量、有效留资成本、曝光、点击、CTR、CPC、私信咨询数、留资转化率、对接数量和对接成本。

### 本月累计

当月 1 日至昨日的累计留资量、累计留资成本、累计对接量和累计对接成本。成本必须使用累计消耗除以累计数量，不能简单平均每日成本。

### 诊断和建议

每条建议必须包含：

- 优先级；
- 对象；
- 建议动作；
- 建议幅度；
- 数据依据；
- 观察窗口；
- 缺失证据；
- 是否需要人工确认。

## 7. 人工调整闭环

系统可以提出：

| 建议 | 人工执行方式 |
|---|---|
| 暂停计划 | 运营在本地推后台手动暂停 |
| 降低预算 | 运营手动填写调整后的预算 |
| 增加预算 | 运营根据建议小幅增加并观察 |
| 调整出价 | 运营手动修改并记录实际值 |
| 替换素材 | 运营手动上传或切换素材 |
| 检查回传/承接 | 运营确认后反馈结果 |

日报不能把“建议动作”写成“已经执行”。下一次运行读取执行反馈时，必须区分：

```text
未执行
已执行且改善
已执行但无改善
部分执行
执行方式不同
```

如果建议未执行，不能评价该建议是否有效，也不应重复制造同一条建议。

## 8. 失败处理

- 浏览器下载失败：不生成正常日报，记录失败原因并告警；
- 文件不是完整报表：标记 `partial` 或 `missing`，不生成高风险调整建议；
- 石墨反馈缺失：正常生成前端投放分析，但有效留资、对接和相关成本标记为待补录；
- 计划和素材无法关联：保留未关联金额，不强行归因；
- LLM 诊断失败：保留确定性规则结果，输出 `CHECK_DATA`；
- 浏览器登录失效或出现验证码：停止自动化，等待人工重新登录。

## 9. 当前验收顺序

```text
浏览器登录态检查
→ 下载昨日两份报表
→ 文件和日期校验
→ 自动识别与导入
→ 指标和账户/计划/素材对账
→ 生成昨日与本月累计
→ 生成建议
→ 人工执行并回填结果
```

API 连接器保留为未来可选路线，不阻塞当前文件下载方案。
