# 下一步素材测试与建计划执行方案

更新时间：2026-08-10

## 1. 总体策略

下一步不要乱开很多计划，也不要每条素材单独开计划。当前账户应该采用：

```text
1 个主力复刻计划
+ 2 个测新计划
+ 1 个搜索承接计划（如果后台能开）
```

核心目标不是单纯增加留资量，而是提高：

- 有效留资量；
- 电话接通率；
- 微信通过率；
- 后续可沟通线索比例；
- 有效留资成本稳定性。

## 2. 下一步优先做什么素材

### 2.1 优先级 1：27届时间线 / 回国还是留海外

这是目前最应该复制的方向。

原因：

- `27届海归找工作 回国还是留在海外？` 历史表现最好。
- 总 CPL 为 **167.03 元**。
- 2026-08-06 单日跑出 **5 个留资**，CPL **86.00 元**。
- 说明“27届 + 回国/留海外选择 + 时间线”这个角度已经被数据验证过。

注意：不要继续硬投原素材，要做改版。

建议做 3 条：

| 素材编号 | 主题 | 目的 |
| --- | --- | --- |
| A1 | 27届留学生回国求职，现在准备晚不晚？ | 吸引 27 届学生/家长 |
| A2 | 27届海归，回国还是留海外？先看这 3 点 | 复刻原爆点 |
| A3 | 27届家长别替孩子乱规划，先看求职时间线 | 吸引家长决策人群 |

开头话术：

```text
27届留学生，如果你打算回国求职，现在不是纠结回不回国，而是要先把时间线排清楚。
```

或者：

```text
27届海归现在最容易犯的错，不是准备晚，而是方向还没定就开始乱投。
```

中段内容：

```text
你至少要先确认三件事：
第一，你是准备回国就业，还是继续留海外；
第二，你目标岗位到底适不适合你的背景；
第三，你现在的简历和经历，能不能支撑你投这个方向。
```

筛选句：

```text
如果你只是随便看看，可以先收藏。
如果你近期真的在准备秋招、实习或回国求职，再预约沟通。
提交后顾问会先电话确认你的情况，再判断是否适合继续沟通。
```

### 2.2 优先级 2：隐形红利 / 信息差

这个方向对应当前素材：

```text
留学生求职 这三个隐形红利千万别错过
```

它目前数据相对健康：

- 消耗 **435.02 元**；
- 留资 **2 个**；
- CPL **217.51 元**；
- CPM **176.55 元**；
- 属于新素材里相对可继续测试的方向。

建议做 2 条：

| 素材编号 | 主题 | 目的 |
| --- | --- | --- |
| B1 | 留学生求职的 3 个信息差，很多人投简历后才知道 | 延续“隐形红利”方向 |
| B2 | 海归求职不是学历越高越稳，而是你有没有用对策略 | 提高点击和筛选 |

开头话术：

```text
留学生求职不是只看学历，有 3 个信息差，很多人到投简历没反馈才发现。
```

或者：

```text
很多海归不是能力不行，而是从一开始就投错了方向。
```

中段内容：

```text
第一，不同岗位看重的经历完全不一样；
第二，回国求职和海外求职的筛选逻辑不同；
第三，你的简历不是写得越满越好，而是要和目标岗位匹配。
```

筛选句：

```text
如果你已经开始投递但反馈少，或者还没确定方向，可以先预约一次情况确认。
不方便电话沟通的同学，不建议直接留资。
```

### 2.3 优先级 3：强筛选口播

这个方向是为了解决当前线索质量问题：

- 电话打不通；
- 微信不通过；
- 让留微信也不留；
- 有留资但有效率不够高。

这类素材的目的不是拉最多留资，而是筛出更愿意沟通的人。

建议做 3 条：

| 素材编号 | 主题 | 目的 |
| --- | --- | --- |
| C1 | 不是所有留学生都适合现在找求职辅导 | 筛掉低意向 |
| C2 | 如果你只是随便看看，先别留资 | 提高有效率 |
| C3 | 留学生求职咨询前，先确认这 3 个问题 | 提高线索质量 |

开头话术：

```text
如果你只是随便看看，先别急着留资。这条更适合近期真的在准备求职的留学生。
```

或者：

```text
不是所有留学生都适合马上做求职规划，先看你是不是这三类人。
```

中段内容：

```text
第一，你已经确定回国还是留海外；
第二，你有明确目标方向，或者至少有几个备选方向；
第三，你愿意电话沟通自己的背景和求职进度。
```

强筛选句：

```text
如果你不方便电话沟通，或者只是想随便了解一下，可以先收藏。
如果你近期确实要准备求职，再留下常用手机号，顾问会先电话确认情况。
```

这个方向可能让留资量下降，但有效率会提高。当前账户需要提高有效率。

## 3. 不建议继续主推的素材方向

### 3.1 智商税类

例如：

```text
海归回国找机构，到底是不是智商税？
```

不建议继续主推的原因：

- 已经消耗 **488.53 元**；
- 留资 **0 个**；
- 这类标题容易吸引好奇点击；
- 但用户不一定真的想咨询。

可改成：

```text
找留学生求职机构前，先问清这 3 个问题。
```

不要再用“智商税”做主标题。

### 3.2 泛焦虑类

例如：

```text
留学生求职太难了
海归找工作越来越难
别再乱投简历了
```

不是不能用，而是必须加具体对象和下一步。

差的表达：

```text
留学生别乱投简历，盲目海投只会错过机会。
```

更好的表达：

```text
已经开始投递但没反馈的 27 届留学生，先别继续海投，先检查这 3 个问题。
```

## 5. 怎么建计划去测

### 5.1 不建议的建法

不要这样建：

```text
素材1 一个计划
素材2 一个计划
素材3 一个计划
素材4 一个计划
素材5 一个计划
```

原因：

- 预算被打散；
- 每个计划跑不出数据；
- 系统学习慢；
- 很难判断是素材问题还是计划冷启动问题；
- 新手容易越调越乱。

### 5.2 推荐计划结构

建议建：

```text
1 个主力复刻计划
2 个测新计划
1 个搜索承接计划（可选）
```

## 6. 计划 1：主力复刻计划

目标：复制 2026-08-06 的成功方向。

| 项目 | 设置 |

| 素材 | A1、A2、A3 |
| 素材数量 | 3 条 |

为什么：

- 这个方向历史最强；
- 但原素材疑似疲劳；
- 所以要用新素材复刻旧方向。

## 11. 每个计划放几条素材

新手记住：

```text
一个计划放 2-4 条素材，不要只放 1 条，也不要放 10 条。
```

原因：

- 只放 1 条：计划表现完全被单条素材决定，风险高。
- 放太多条：系统分配不均，看不出谁真正有效。
- 2-4 条：最适合小预算赛马。

建议：

| 计划 | 素材数 |
| --- | ---: |
| 主力复刻计划 | 3 条 |
| 测新计划 A | 2 条 |
| 测新计划 B | 3 条 |
| 搜索计划 | 1-2 条 |

## 12. 测试多久停，多久加

### 第 1 天

不要频繁改。

只看：

- 有没有消耗；
- CTR 是否明显低于 0.8%；
- 有没有私信/留资；
- 是否出现异常消耗。

第 1 天只处理极端情况：

| 情况 | 动作 |
| --- | --- |
| CTR 低于 0.5%，消耗还在走 | 暂停素材 |
| 0 私信、0 留资，且消耗接近 300-500 元 | 降预算/停 |
| 素材被拒或违规 | 立即处理 |
| 预算/定向填错 | 立即修正 |

### 第 2 天

开始看趋势。

| 情况 | 动作 |
| --- | --- |
| 有留资，但无有效 | 不加预算，改筛选 |
| 有效留资成本低于 330 元 | 保留 |
| 有效留资成本 330-500 元 | 继续观察 |
| 有效留资成本高于 500 元 | 控预算 |

### 第 3 天

做决策。

| 3 日结果 | 动作 |
| --- | --- |
| 有效留资成本低于 330 元，且能触达 | 加预算 10%-20% |
| 有效留资成本 330-500 元 | 保持预算继续观察 |
| 有效留资成本高于 500 元 | 降预算 20%-30% |
| 消耗超过 700 元仍 0 有效留资 | 停 |
| CTR 连续低于 0.8% 且无留资 | 停素材，重做 |

## 15. 两个重要提醒

### 15.1 不要为了留资量牺牲有效率

当前已经出现：

```text
留资有，但电话打不通、微信不通过。
```

所以素材里一定要提前写：

```text
提交后会电话确认情况。
不方便电话沟通的同学，可以先收藏。
```

这句话可能会让留资变少，但有效率会变好。

### 15.2 不要一天内反复调

新手最容易上午没转化就关，下午看到一个线索又加预算。

建议只按 3 个时间看：

| 时间 | 做什么 |
| --- | --- |
| 上午 10 点 | 查异常，不大改 |
| 下午 3 点 | 看 CTR、私信、留资，有严重问题才控 |
| 晚上 10 点 | 做第二天调整 |

不要每小时操作后台。

本地推要看 2-3 天，不是看 2-3 小时。
