### 1.3 调度和失败验收

- [ ] 每天 09:00 自动启动下载任务
- [ ] 下载失败时不生成正常日报
- [ ] 登录失效时停止并提示人工登录
- [ ] 验证码/短信验证出现时停止并提示人工处理
- [ ] 下载重试不会重复导入或重复生成建议
- [ ] 原始文件保留，记录下载时间和统计日期

浏览器登录态的存储位置必须是本机受保护的浏览器配置，不记录密码，不把登录 Cookie 写入日志或提交到仓库。

### 1.4 数据关联验收

- [ ] 计划明细和素材明细能否直接关联
- [ ] 如果不能，明确记录缺失字段
- [ ] `plan_material_relation` 是否带有效期
- [ ] 同一素材挂在不同计划时历史是否可追溯
- [ ] 账户汇总与计划汇总能够对账
- [ ] 计划汇总与素材汇总无法对账时能展示未关联金额

## 2. 石墨文档 API

### 2.1 认证验收

- [ ] 确认 OAuth 授权模式
- [ ] 确认是否支持服务端长期调用
- [ ] 确认 Token 有效期和刷新机制
- [ ] 确认应用对目标文档有读写权限

### 2.2 写入验收

- [ ] 是否支持按区块、表格或位置写入
- [ ] 全量写入是否会覆盖人工填写内容
- [ ] 是否有版本号、并发编辑和幂等机制
- [ ] 是否能读取人工填写的执行反馈
- [ ] 写入失败后重试不会重复插入日报
- [ ] 能否以 `run_id` 或 `data_date` 定位和更新内容

### 2.3 内容策略

第一版推荐分离写入区域：

| 区域 | 写入方 |
|---|---|
| 日报数据区 | Agent |
| 建议反馈区 | 人工 |

石墨线索表至少需要能够读取：

| 字段 | 用途 |
|---|---|
| lead_id | 与平台留资关联 |
| lead_date | 按留资产生日期归属 |
| is_valid / 有效留资 | 计算有效留资量 |
| 是否对接 | 计算对接数量 |
| contacted_at（如有） | 记录实际对接时间 |
| feedback_updated_at | 记录人工补填时间 |

对接数量统一定义为：石墨线索表中 `是否对接=是` 的行数。第一版按 `lead_date` 归属；如果后续需要按实际对接日期归属，必须另加 `contacted_at`，不能用反馈更新时间替代。

如果无法稳定读取石墨反馈，则反馈以数据库为准，石墨只作为展示和人工协作界面。

## 3. 企业微信到个人微信

### 3.1 可行性验收

- [ ] 注册企业微信
- [ ] 创建自建应用
- [ ] 获取 CorpID / Secret / AgentId / touser
- [ ] 配置可信 IP
- [ ] 生成微信插件二维码
- [ ] 个人微信扫码后可接收测试消息
- [ ] 消息格式支持当前选定类型
- [ ] 超长消息可降级为摘要加石墨链接

### 3.2 推送内容

只推送：

- 账户消耗
- 单个留资成本、有效留资成本及其数据完整度
- P0/P1 动作
- 异常计划
- 石墨文档链接

完整计划表、素材表、证据和诊断细节写入石墨。

## 4. n8n

### 4.1 调度验收

- [ ] Cron 表达式 `30 8 * * *`
- [ ] 时区配置为 `Asia/Shanghai`
- [ ] 工作流处于发布状态
- [ ] API 拉取失败可重试 3 次，间隔 30 秒
- [ ] Error Trigger 捕获失败并告警
- [ ] 明确错过调度后的补偿策略

### 4.2 幂等验收

- [ ] 同一账户、同一统计日、同一版本重复运行不会重复累计
- [ ] `run_id` 唯一
- [ ] 重复运行能识别为重跑
- [ ] 石墨写入不会重复插入
- [ ] 企业微信推送不会因重试无限重复发送

## 5. 数据质量验收

- [ ] 账户、单元、素材数据总额能够对账
- [ ] 部分 API 失败时不会生成假日报
- [ ] 数据不完整时会明确标记
- [ ] 9 月数据能够复现已知的计划活跃时间线
- [ ] 8.28 深转能够被识别为历史表现好、后期衰退
- [ ] 素材无法与计划关联时会明确提示
- [ ] 人工筛选延迟时不生成高风险动作
- [ ] 昨日建议未执行时不会重复制造新建议

## 6. 本月累计验收

- [ ] 每日 09:00 报告明确标注“本月截至昨日”
- [ ] 本月留资量等于当月日留资量之和
- [ ] 本月留资成本等于本月累计消耗 / 本月累计留资量
- [ ] 本月对接量等于石墨表中当月线索且 `是否对接=是` 的数量
- [ ] 本月对接成本等于本月累计消耗 / 本月累计对接量
- [ ] 不对每日成本做简单平均
- [ ] 石墨后续补填对接结果后，本月累计可以回算
- [ ] 重复运行不会重复累计本月数据

## 7. 通过标准

连接器只有在以下条件同时满足时，才能进入实时日报主链路：

1. 权限、字段和数据日期口径已验证。
2. 重试、token 轮换和服务重启测试通过。
3. 能够进行对账和幂等重跑。
4. 失败时会阻止高风险建议生成。
