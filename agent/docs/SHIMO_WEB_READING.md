## 每日同步规则

- 任务先按统计日期寻找既有行，读取 E（有效留资）与 M（对接）并入日报；空白为待补录，0为人工确认的零。
- 再写 B（消耗）、C（平台留资）、G（曝光）、H（点击）、K（私信）。这些值只来自本地推下载报表。
- D、F、I、J、L、N 为现有公式，E、M为人工列，全部写前快照并在刷新后核对未变。
- 日期不存在、行重复、人工值不是数字、权限/登录失败、保存复核失败时停止石墨写入并在 `shimo_sync.json` 留下失败原因；不会自动插行或覆盖人工列。

## 建议与执行反馈闭环

- Agent 仅向当日行的 P（建议 ID）和 Q（建议动作）写入建议；任何本地推调整仍由人工确认和执行。
- R:W 是人工维护区：执行状态、实际动作、执行时间、执行后 1 日结果、执行后 3 日结果和备注。写入前会快照，刷新后确认这些单元格没有变化。
- P/Q 已有内容时，只有和本次生成内容完全一致才允许安全重跑；不同内容会停止，避免覆盖人工修订。当天没有建议不会清除旧内容。
- 每日任务会读取前一统计日的反馈；建议 ID 与执行状态逐行对应时，才会幂等地写入本地状态库，原始读取结果始终保存到 `shimo_execution_feedback.json`。
