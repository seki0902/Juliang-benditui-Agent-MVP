- 当前账户不是简单“加预算放量”的阶段，而是 **先控低效消耗，再把预算集中到有效留资更好的素材方向**。

- 最值得复盘的是 **2026-08-06**：平台留资 6、有效留资 5、有效留资成本 143.07、CTR 2.17%，这是这几天最健康的一天。
- 最需要控制的是低 CTR、0 留资、0 私信的消耗行：截图中有一行曝光 5,549、点击 18、CTR 0.32%、0 留资、0 私信，这类素材/计划应暂停或降到极低预算排查。

## 7. 线索质量与承接问题

结合业务反馈，当前无效/低效线索主要有三类：

| 问题 | 判断 | 处理 |
| --- | --- | --- |
| 申请不通过 | 用户意向弱或没有建立信任 | 电话/短信提醒一次，再申请一次；二次不通过就降级 |
| 留电话但无法触达 | 表单门槛低，用户随手留资 | 5 分钟、30 分钟、2 小时各触达一次；仍不接标 C 类 |
| 让留微信也不留 | 抗拒私域或低意向 | 不再投入大量销售时间，归为 B/C 类 |

### 线索分级建议

| 等级 | 定义 | 是否计入有效 |
| --- | --- | --- |
| A 类 | 微信通过、电话接通、明确需求、可继续跟进 | 计入有效 |
| B 类 | 电话真实但暂未加微信、有初步意向、可二次触达 | 暂计待确认 |
| C 类 | 空号、错号、不接、拒绝、无需求、不加微信且无法触达 | 不计有效 |

### 跟进 SOP

- 留资后 5 分钟内电话首呼。
- 未接通，10-15 分钟后第二次触达。
- 同步短信/私信说明身份和添加微信理由。
- 微信申请未通过，电话/短信提醒一次，再申请一次。
- 二次仍不通过，不再反复戳，标记低意向。
- 当天未通过微信但电话接通过的线索，次日二次唤醒。

### 单独开计划的条件

只有满足以下条件的素材，才值得单独开计划：

- 连续 2-3 天有留资；
- 有效留资成本低于账户平均；
- 至少有 A/B 类可触达线索；
- CTR 不低于账户均值，且没有明显标题党/误导；
- 不是只靠单日偶然波动跑出来。

## 9. 规则映射

- **3 日观察周期**：不要用 2026-08-10 上午数据直接判断全部计划生死；但连续多天 0 留资或 3 日有效成本明显高的素材可以关停或降预算。
- **30% 测新预算**：新素材和新计划预算控制在 20%-30%，避免测新预算过高冲散账户模型。
- **预算递增约 20%**：可加预算素材只加 10%-20%，不要单日翻倍。
- **CTR-CVR 联动**：低 CTR + 0 留资优先判断为素材/人群吸引力问题；CTR 不低但无有效留资，优先判断为承接/筛选问题。
- **线索 1-2 小时跟进**：留资后必须快速电话确认和引导微信，延迟会放大“不通过/不触达”问题。
- **数据回传**：如果不把有效留资、预约、成交回传给平台，系统会继续优化“容易留资的人”，而不是“真正有效的人”。

## 12. 下次判断阈值

- 加预算：有效留资成本低于账户均值，且至少有 A/B 类可触达线索，加 10%-20%。

## 14. 投放小白执行版：每天照着做

这一节按新手操作顺序写，不需要先理解所有专业词，先照流程跑起来。

### 14.1 每天早上先看 5 个数

每天不要一上来就关计划或加预算，先打开报表看这 5 个数。

| 指标 | 看什么 | 你现在怎么用 |
| --- | --- | --- |
| 消耗 | 今天花了多少钱 | 判断有没有乱花钱 |
| 留资量 | 后台来了几个线索 | 只代表前端数量，不代表质量 |
| 有效留资量 | 真正能接通/能沟通的人 | 这是最重要的核心指标 |
| CTR | 点击率，点击/曝光 | 判断素材有没有吸引力 |
| 有效留资成本 | 消耗/有效留资量 | 判断这个素材值不值得继续花钱 |

新手优先级：

1. 先看有效留资量。
2. 再看有效留资成本。
3. 再看 CTR。
4. 最后才看后台留资成本。

不要只因为后台 CPL 低就加预算。如果后台 CPL 低，但电话打不通、微信不通过，这个素材也不能加。

| 项目 | 当前参考线 | 用法 |
| --- | ---: | --- |
| 后台留资成本 | 约 240-250 元 | 只能做前端参考 |
| 有效留资成本 | 约 330-360 元 | 更重要，用来决定加预算 |
| 较差有效成本 | 500 元以上 | 要开始控预算 |
| 严重低效成本 | 700 元以上 | 要考虑停素材/停计划 |
| 健康 CTR | 1.3% 以上 | 可以继续观察或测试 |
| 偏低 CTR | 0.8%-1.0% | 要优化素材 |
| 危险 CTR | 低于 0.8% | 如果还没留资，要停或重做 |

一句话判断：

- 有效留资成本低于 330 元，可以考虑加预算。
- 有效留资成本 330-500 元，先观察，不急加。
- 有效留资成本高于 500 元，开始降预算或换素材。
- 有效留资成本高于 700 元，还没有好线索，基本要停。

### 14.3 每天操作顺序

#### 第一步：先把昨天的数据填进去

每天先按下面表格记录，不要凭感觉判断。

| 日期 | 素材 | 消耗 | 留资量 | 有效留资量 | 有效留资成本 | CTR | 电话接通 | 微信通过 | 动作 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | --- |
|  |  |  |  |  |  |  |  |  |  |

有效留资成本公式：

```text
有效留资成本 = 消耗 / 有效留资量
```

如果有效留资量是 0，就不要算成本，直接看消耗有没有超过止损线。

#### 第二步：先找要停的

先停亏钱的，比找爆款更重要。

满足下面任意情况，就先停或大幅降预算：

| 情况 | 动作 |
| --- | --- |
| 素材连续 2 天 0 留资 | 停或降到最低预算 |
| 消耗超过 500 元还没有 1 个有效留资 | 强控预算 |
| 消耗超过 700 元还没有 1 个有效留资 | 基本停 |
| CTR 低于 0.8%，且没有私信/留资 | 停素材，重做开头 |
| 有留资但全是电话打不通/微信不通过 | 不加预算，改筛选话术 |

对应你现在的数据：

- `海归回国找机构 到底是不是智商税？`：累计 488.53 消耗，0 留资，直接关。
- 截图里曝光 5,549、CTR 0.32%、0 留资、0 私信的那一行：先停或降到极低预算。
- `留学生别乱投简历！盲目海投只会错过机会`：近期 CTR 已经掉到 0.64%、0.46%，先降预算 30%-50%。

#### 第三步：再找能加预算的

新手不要看到有线索就加预算，要同时满足 3 个条件。

| 加预算条件 | 必须满足吗 |
| --- | --- |
| 有效留资成本低于账户平均 | 必须 |
| 线索能接通或能进微信 | 必须 |
| 不是只跑了一天偶然好 | 尽量满足 |

当前可考虑加预算：

- `留学生求职 这三个隐形红利千万别错过`
  - 可以加 10%-20%。
  - 前提是它带来的 2 个留资里，至少 1 个能接通或能继续沟通。

当前不要加预算：

- `27届海归找工作 回国还是留在海外？`
  - 历史数据好，但原素材后面变弱，不建议继续给原版加预算。
  - 正确做法是复制这个方向，重新做 2-3 条新素材。

#### 第四步：最后才决定新开计划

新手最容易犯的错是：一看到素材多，就每条素材开一个计划。

你现在不建议这么做。

正确做法：

| 计划 | 放什么 | 预算 |
| --- | --- | --- |
| 主力计划 | 27届方向的改版素材 | 50%-60% |
| 测新计划 A | 三个隐形红利方向 | 20%-30% |
| 测新计划 B | V计划/强筛选口播 | 10%-20% |

不要 5 条素材开 5 个计划。预算会被打散，系统也学不出来。

### 14.4 明天具体怎么调

如果明天就要操作，可以按这个顺序做。

| 顺序 | 操作 | 对象 | 幅度 |
| ---: | --- | --- | --- |
| 1 | 关停 | `海归回国找机构 到底是不是智商税？` | 关 |
| 2 | 暂停排查 | 曝光 5,549、CTR 0.32%、0 留资那条 | 关或降到最低 |
| 3 | 降预算 | `留学生别乱投简历！盲目海投只会错过机会` | 降 30%-50% |
| 4 | 保留 | `27届海归找工作 回国还是留在海外？` | 不加，保低预算 |
| 5 | 小幅加 | `留学生求职 这三个隐形红利千万别错过` | 加 10%-20% |
| 6 | 观察 | `海归求职有难题 就找爱思益V计划` | 不急加 |

如果你总预算不高，优先保证：

```text
60% 给已经验证过的方向
30% 给新素材测试
10% 留作临时调整
```

### 14.5 怎么判断“素材问题”还是“销售承接问题”

| 现象 | 更可能的问题 | 你该做什么 |
| --- | --- | --- |
| CTR 很低，没人点 | 素材开头/标题不吸引 | 改前 3 秒、封面、标题 |
| CTR 高，但没有留资 | 落地页/表单/人群不匹配 | 改表单话术和筛选条件 |
| 有留资，但电话打不通 | 低意向或表单门槛低 | 素材提前说明会电话确认 |
| 有留资，但微信不通过 | 信任不足或用户抗拒私域 | 先电话确认需求，再引导微信 |
| 私信多，留资少 | 咨询承接没推动留资 | 私信话术要引导预约/留资 |
| 留资多，有效少 | 素材承诺太宽或太低门槛 | 增加“适合谁/不适合谁” |

你的情况是：既有素材衰退，也有承接问题。

- 低 CTR 0 留资的素材，是素材问题。
- 电话无法触达、微信不通过，是线索质量和承接问题。
- 有留资但有效率低，是素材筛选不够。

### 14.6 素材怎么改：直接给方向

你现在不要继续只做“留学生求职很难、快来咨询”这种宽泛素材，要做筛选型素材。

#### 方向 1：27届时间线

适合复制 `27届海归找工作 回国还是留在海外？` 的成功方向。

开头示例：

```text
27届留学生，如果你打算回国求职，现在不是纠结回不回国，而是要先把时间线排清楚。
```

筛选句：

```text
如果你近期真的在准备秋招、实习或回国求职，再预约沟通。
```

#### 方向 2：隐形红利

适合继续测试 `三个隐形红利`。

开头示例：

```text
留学生求职不是只看学历，有三个信息差很多人到投简历才发现。
```

筛选句：

```text
如果你只是随便看看，可以先收藏；如果你已经开始准备投递，再留下联系方式。
```

#### 方向 3：别乱海投

适合重做 `别乱投简历`，不是继续投原版。

开头示例：

```text
海投不是努力，是没有策略。尤其是留学生回国求职，最怕投了很多却没有反馈。
```

筛选句：

```text
适合已经开始投递但反馈少，或者不知道岗位方向怎么选的同学。
```

#### 方向 4：机构避坑

适合重做 `智商税`，但不要继续用强争议标题。

开头示例：

```text
找求职机构前，先问清楚这三个问题，不然很容易花钱但没结果。
```

不要说：

```text
是不是智商税
```

因为它容易吸引好奇点击，但不一定带来真实咨询。

### 14.7 表单和私信怎么改

你说用户“留电话无法触达，让留微信也不留”，所以表单和话术要提前降低误会。

建议表单说明写：

```text
提交后顾问会先电话确认你的求职情况，再根据情况协助添加微信沟通。
请填写本人常用手机号，方便 1 小时内联系。
```

如果能加问题字段，建议加：

| 字段 | 作用 |
| --- | --- |
| 目前年级/毕业年份 | 判断是不是目标用户 |
| 目标方向 | 判断需求是否明确 |
| 是否已开始投递 | 判断意向强弱 |
| 方便联系时间 | 提高接通率 |
| 微信号，选填 | 不强制，但给愿意的人入口 |

私信话术不要直接要微信，可以这样：

```text
同学你好，我们先确认一下你的毕业时间和目标方向。如果情况匹配，再帮你安排顾问进一步沟通。
```

再引导：

```text
后续方案细节会比较多，电话确认后可以通过微信发你整理版建议。
```

### 14.8 申请不通过怎么处理

不要反复戳。

| 次数 | 动作 |
| --- | --- |
| 第一次申请不通过 | 电话/短信提醒一次 |
| 第二次申请不通过 | 再申请一次 |
| 仍不通过 | 标记低意向，不再追 |

短信/电话提醒话术：

```text
你好，我是刚才抖音上你预约留学生求职咨询的顾问，看到你留了信息。我们先电话确认一下你的毕业时间和求职方向，合适的话再通过微信发你建议。
```

### 14.9 一天内什么时候看数据

新手不要每小时都改。

建议只看 3 次：

| 时间 | 看什么 | 能不能操作 |
| --- | --- | --- |
| 上午 10:00 | 看是否有异常消耗、审核、0 点击 | 只排查，不大改 |
| 下午 15:00 | 看 CTR、点击、私信、留资 | 明显异常可控预算 |
| 晚上 22:00 | 看全天结果 | 做第二天调整 |

不要因为上午没有留资就关计划，尤其是预算还没花够、样本还小的时候。

但如果出现下面情况，可以当天处理：

- CTR 低于 0.5%，且花了不少钱；
- 0 私信、0 留资，还持续消耗；
- 素材明显违规或被拒；
- 定向/排除包设置错了；
- 预算小数点填错。

### 14.10 最简单的决策口诀

```text
先停亏钱的，再保能跑的，最后小幅加好的。
```

具体一点：

```text
低 CTR 0 留资：停。
有点击没有效：改筛选。
有效成本低：小加。
历史好但变弱：做改版，不硬加。
每次加预算：只加 10%-20%。
```
