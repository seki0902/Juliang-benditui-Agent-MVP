# 投放诊断增强参考

本文件把通用付费广告 Skill/增长诊断框架转成本地推可用的分析规则。用于平台逻辑、素材适投判断、计划架构、止损/放量、小白执行手册。

## 1. 借鉴点与本地推映射

| 通用投放框架 | 本地推映射 | 使用方式 |
| --- | --- | --- |
| Click / Convert / Close | 点击 / 留资 / 有效留资或成交 | 先定位断点，再给动作 |
| Unit economics | 有效留资成本、成交 CAC、ROI | 不按表面 CPL 放量 |
| Customer quality | 有效率、微信通过、电话接通、到店/预约/成交 | 低价低质不能算好计划 |
| Campaign architecture | 稳定计划、测新计划、搜索承接计划 | 避免每条素材单独开计划 |
| Kill criteria | 停素材、停计划、降预算阈值 | 用明确阈值减少情绪化操作 |
| Scaling triggers | 加预算条件 | 只在质量和稳定性达标后小幅加 |
| Creative frameworks | Hook、单一卖点、意向筛选、下一步承诺 | 判断素材是否适合继续投 |

## 2. 平台逻辑如何分析

平台诊断要按漏斗分层，不要把所有问题都归因给“系统不给量”。

### 2.1 Click 点击层

看：曝光、点击、CTR、点击成本、CPM/ECPM。

| 现象 | 可能原因 | 动作 |
| --- | --- | --- |
| 曝光多、CTR 低 | 素材前 3 秒弱、标题不吸引、人群不匹配 | 换素材开头、封面、标题；不要先加预算 |
| CTR 高、点击成本低 | 有吸引力，先看后链路质量 | 不急放量，继续看留资和有效率 |
| CPM 高、CTR 也低 | 流量贵且素材弱 | 控预算，优先换素材 |
| CPM 低、CTR 低 | 平台给便宜流量，但用户不感兴趣 | 换人群/素材承诺 |

### 2.2 Convert 留资层

看：点击到留资 CVR、留资数、留资 CPL、私信咨询到留资转化率。

| 现象 | 可能原因 | 动作 |
| --- | --- | --- |
| CTR 高但 CVR 低 | 素材吸引了低意向人群，表单/承接不匹配 | 加筛选话术，改表单字段 |
| 私信多但留资少 | 私信承接没有推动下一步 | 私信话术增加预约/电话确认 |
| 留资多但成本高 | 流量价格或转化效率有问题 | 先看 3 日均值，再控预算 |
| 留资成本低但有效率差 | 虚假繁荣，低质流量 | 不加预算，优化筛选 |

### 2.3 Close 有效承接层

看：有效留资、微信通过、电话接通、预约、成交、ROI。

| 现象 | 可能原因 | 动作 |
| --- | --- | --- |
| 电话无法触达 | 表单门槛低、用户随手留资 | 素材和表单提前说明会电话确认 |
| 微信不通过 | 信任不足、用户没准备深入沟通 | 先电话确认需求，再给加微信理由 |
| 有效少但留资不少 | 素材承诺太宽或过度福利化 | 增加“适合谁/不适合谁” |
| 有效成本高但成交好 | 高意向高价值线索 | 保留，不要只看前端 CPL |

## 3. 如何判断素材适不适合投放

判断素材不要只看 CTR，也不要只看留资 CPL。用“五格评分”。

### 3.1 素材五格评分

| 维度 | 好素材表现 | 差素材表现 |
| --- | --- | --- |
| Hook | 前 3 秒能说清用户痛点 | 开头泛泛而谈、像品牌宣传 |
| Promise | 承诺的是下一步动作，不是夸大结果 | 暗示保 offer、包结果、过度焦虑 |
| ICP fit | 能筛出目标年级/需求/地区/阶段 | 谁都能点，低意向多 |
| Conversion path | 用户知道提交后会发生什么 | 用户不知道会电话/加微信 |
| Compliance | 没有保证、夸大、误导、敏感承诺 | 有确定性就业/名企/收入承诺风险 |

### 3.2 数据适投判断

| 数据表现 | 判断 | 动作 |
| --- | --- | --- |
| CTR 高、有效留资成本低、微信/电话能触达 | 优胜素材 | 小幅加预算 10%-20% |
| CTR 高、留资多、有效率低 | 吸引低意向 | 不加预算，改筛选 |
| CTR 低、无私信、无留资 | 素材不适投 | 停投或重做 |
| CTR 低、但有效率高 | 量小但质量好 | 保留小预算，优化标题和前 3 秒 |
| 留资 CPL 低、但电话不通/微信不通过 | 虚假低成本 | 不加预算，优化表单与承接 |
| 单日爆发、后续快速衰退 | 可能素材疲劳或偶然波动 | 做改版，不硬加原素材 |

### 3.3 本地推素材适投红线

满足任意一条，优先停或降预算：

- 连续 2 天 0 留资，且消耗不低。
- 消耗达到目标有效留资成本的 1.5-2 倍，仍没有有效留资。
- CTR 低于 0.8%，且没有私信/留资。
- 有留资但绝大多数无法触达、拒绝微信、明确无需求。
- 文案靠过度承诺、恐吓、强福利获取线索，导致有效率差。

## 4. 计划架构与素材赛马

不要默认“每条素材一个计划”。计划的作用是让系统学习相对稳定的人群和素材方向；开太散会稀释预算。

### 4.1 推荐结构

| 计划类型 | 作用 | 素材数量 | 预算占比 |
| --- | --- | ---: | ---: |
| 稳定计划 | 保基础量和账户模型 | 2-4 条稳定素材 | 50%-70% |
| 测新计划 | 测新 hook、新角度、新筛选话术 | 2-4 条新素材 | 20%-30% |
| 搜索承接计划 | 承接主动需求 | 搜索专用素材/文案 | 10%-20% |
| 单素材放大计划 | 只给已验证爆款候选 | 1 条或同方向 2 条 | 视效果小幅增加 |

### 4.2 单独开计划的条件

素材满足以下条件才值得单独开：

- 至少跑过 2-3 天或有足够消耗样本。
- 有效留资成本低于账户均值。
- A/B 类有效线索占比高。
- CTR 不低于账户均值。
- 没有明显合规风险或误导承诺。
- 不是只有单日偶然爆发。

## 5. 止损规则与放量触发器

### 5.1 Stop / Replace

| 条件 | 动作 |
| --- | --- |
| 消耗 >= 1.5 倍目标有效留资成本，0 有效留资 | 降预算或暂停 |
| 消耗 >= 2 倍目标有效留资成本，0 有效留资 | 停素材/计划 |
| 连续 2-3 天 CTR 低于账户均值且无转化 | 换素材 |
| 有效留资率低于 40% | 停止放量，修正筛选 |
| 线索大量无法触达 | 先改表单和承接，不加预算 |

### 5.2 Hold

| 条件 | 动作 |
| --- | --- |
| 新素材未满 2-3 天，消耗样本小 | 继续观察 |
| 成本单日升高但 3 日均值可接受 | 不动 |
| CTR 低但有效线索质量高 | 保留小预算，优化前端 |
| 后台提示优化但业务指标可接受 | 不盲从提示 |

### 5.3 Scale

同时满足才加预算：

- 3 日有效留资成本低于账户均值。
- 有效留资率稳定，不是只看表面留资。
- 电话接通/微信通过/预约至少一项质量指标达标。
- CTR 没有连续下滑。
- 没有明显素材疲劳或合规风险。

放量方式：

- 单次加 10%-20%。
- 加后观察至少 24 小时，最好看 2-3 天。
- 成本上升超过 20%-30% 且有效率下降时，回退预算。
- 不要一天内连续多次加预算。

## 6. 单位经济账

本地推要从“留资 CPL”升级到“有效留资成本”和“成交 CAC”。

| 指标 | 公式 | 用法 |
| --- | --- | --- |
| 留资 CPL | 消耗 / 留资数 | 看前端成本 |
| 有效留资成本 | 消耗 / 有效留资数 | 决定是否加预算 |
| 触达成本 | 消耗 / 电话接通或微信通过数 | 判断销售能不能接住 |
| 预约成本 | 消耗 / 预约数 | 判断业务机会 |
| 成交 CAC | 消耗 / 成交数 | 最终投放质量 |
| ROI | 成交金额 / 消耗 | 有成交数据时优先 |

避免三个误区：

- 不要把低 CPL 当作胜利；低 CPL 但有效率差是低质流量。
- 不要把点击、私信、留资当作最终结果；最终要看可触达和成交。
- 不要平均掩盖问题；必须按素材、计划、日期拆开看。

## 7. 小白诊断顺序

每次分析按这个顺序输出：

1. 哪些要停：先止损。
2. 哪些要降：控制风险。
3. 哪些要保：保留可观察样本。
4. 哪些能加：只小幅加。
5. 哪些要重做：给具体素材方向。
6. 明天怎么操作：给表格，不只讲原则。

最小输出表：

| 对象 | 问题 | 证据 | 动作 | 幅度 | 复盘时间 |
| --- | --- | --- | --- | --- | --- |
| 素材/计划 | CTR低/有效差/成本高 | 数据 | 停/降/保/加/重做 | 百分比或预算 | 日期 |

## 8. 素材改版模板

### 8.1 强筛选口播

结构：

1. 指明人群：年级、身份、阶段。
2. 点出问题：投递没反馈、方向不清、回国/留海外纠结。
3. 给下一步：电话确认、评估方向、预约沟通。
4. 筛掉低意向：随便看看先收藏，近期要准备再留资。

### 8.2 搜索承接素材

结构：

1. 用疑问句承接搜索意图。
2. 前 3-5 秒直击问题。
3. 不要做强剧情，重点回答“我为什么现在要咨询”。
4. 表单说明后续电话确认，再进入微信。

### 8.3 避坑类素材

结构：

1. 不用强争议词制造好奇点击。
2. 用判断标准替代恐吓表达。
3. 明确适用对象。
4. 让用户做低门槛下一步，而不是承诺结果。
