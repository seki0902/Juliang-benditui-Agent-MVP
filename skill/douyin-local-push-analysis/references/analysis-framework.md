# 抖音本地推数据分析框架

本框架用于把投放规范转化为可复用的数据分析流程。优先服务于复盘、诊断、预算/出价建议、素材测新、搜索广告、线索质量和销售跟进分析。

## 1. 必备字段

尽量要求用户提供表格或 CSV/XLSX，字段可同义映射。

| 类别 | 字段 |
| --- | --- |
| 时间 | 日期、小时/时段、投放天数、计划创建时间 |
| 层级 | 账户、项目/计划、广告、素材、素材类型、广告类型(通投/搜索) |
| 策略 | 出价策略、出价、预算、投放时段、付费方式、定向、关键词/匹配方式 |
| 消耗流量 | 消耗、展示、点击、CTR、CPM/ECPM |
| 转化 | 转化数/线索数、转化率(CVR)、转化成本(CPA/CPL)、有效线索、有效率 |
| 后端 | 跟进时长、到店/预约/成交、成交金额、ROI、回传状态 |
| 运营状态 | 计划状态、素材审核状态、拒审原因、预算/出价/时段修改记录 |

字段不足时也要继续分析，但必须说明限制。例如缺少有效线索时，只能判断前端线索成本，不能判断真实获客质量。

## 2. 指标公式

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| CTR | 点击数 / 展示数 | 判断素材吸引力和文案激进度 |
| CVR | 转化数 / 点击数 | 判断承接页、表单、用户意向、销售匹配 |
| CPL/CPA | 消耗 / 线索或转化数 | 核心成本指标 |
| CPM | 消耗 / 展示数 * 1000 | 判断流量价格 |
| ECPM | 视后台口径为准 | 与出价、CTR、CVR、行业大盘和账户模型相关 |
| 有效率 | 有效线索 / 总线索 | 评估前端成本是否透支后端质量 |
| ROI | 成交金额 / 消耗 | 有成交数据时优先于学习期/表面成本 |

## 3. 分析优先级

1. 先看业务目标：线索成本、有效线索、成交、ROI，而不是单看学习期或平台提示。
2. 先看 3 日均值，再看单日异常。
3. 先分通投/搜索、新/老计划、素材类型，再做总账判断。
4. 先排查数据质量和跟进时效，再把问题归因给投放系统。
5. 先判断是否需要保持稳定，再决定是否调整预算、出价、时段或关停。

## 4. 常见诊断模式

### 成本高

检查顺序：
1. 是否只是一日波动，是否未满 2-3 天最小测试周期。
2. CTR、CVR 是否失衡：CTR 高但 CVR 低通常说明吸引强但承接/人群质量弱；CTR 低但 CVR 高通常说明量少但质量可接受。
3. ECPM/CPM 是否高于账户历史或行业大盘假设。
4. 是否近期频繁改预算、出价、时段、关停/重启。
5. 是否新计划预算占比过高，冲散账户模型。
6. 是否线索跟进慢，导致有效率/成交下降。

输出建议要区分：
- 短期波动：Hold，观察 3 日均值。
- 真实劣化：控制预算、替换素材、修正承接或销售跟进。
- 结构问题：拆分账户/计划、隔离素材类型、控制测新预算。

### 成本低但质量差

重点不要只庆祝低成本。检查有效线索率、成交率、跟进反馈、微信/门店承接。如果低成本伴随质量差，可能是低质流量或素材误导。

### 有量无转化

重点查 CVR、落地页/表单、销售话术、线索跟进时效、素材承诺与产品是否匹配。不要只通过加预算解决。

### 无量或跑不动

检查出价是否低于大盘、预算是否过低、素材是否弱、定向是否过窄、搜索关键词是否不足、是否频繁降价伤害模型。起量应表现为短时间消耗突然上升，而不是全天匀速小额消耗。

### 数据大涨/大跌

先排查同行暂停、大盘波动、重大节日/活动、政策节点、账户新启动、样本量过低。排查后仍波动超过 50% 时，建议进入风险控制。

## 6. 建议的判断阈值

这些阈值来自用户提供的规范，需结合行业、城市、产品、账户历史修正。

| 项目 | 参考规则 |
| --- | --- |
| 观察周期 | 最小 2-3 天；系统完整周期按 3 天评估 |
| 稳定周期 | 账户可能需 5-10 次波动后进入稳定 |
| 测新预算 | 新计划/新素材预算约占总预算 30%，稳定计划约 70% |
| 新素材上新 | 无报量时每周 5-10 条；有爆量时每天 1-2 条 |
| 搜索关键词 | 200-300 个；品牌词、竞品词、行业词组合 |
| 搜索出价 | 通投出价基础上约上浮 10% |
| 搜索预算 | 初期 300-500 元/日；至少保留基础预算 |
| 预算递增 | 放量阶段按约 20% 递增，避免单日翻倍 |
| 时段最低长度 | 指定时段尽量不低于 6 小时，保持连续 |
| 线索跟进 | 留资后 1-2 小时内跟进；每延迟 1 小时响应率显著衰减 |
