# 抖音本地推投放规则整理

以下内容由用户提供的 TXT 规范整理，供投放数据分析和运营决策映射使用。它不是平台官方实时政策。

## 1. 底层逻辑

- 本地推广告链路可按 "需求制造 -> 搜索承接 -> 私域/销售解决" 理解。
- 平台优先保证生态和盈利，出价、消耗、赔付、流量分配都可能体现长期均值平衡。
- 线上投放只是获客起点，后端销售话术、跟进速度、门店/私域承接会显著影响真实 ROI。
- 学习期本身不是盈利目标；中小预算应聚焦实际转化成本、有效线索和 ROI。
- 公域适合制造需求，搜索广告适合承接主动需求，私域/线下适合完成深度决策。

## 2. 成本波动与观察周期

- 用 3 天作为主要评估单位，不要用单个 24 小时或几小时数据判断计划生死。
- 成本可能出现 "高-低-高-低" 波动，冷启动阶段需要经历 3-4 轮完整波动。
- 单日极端成本可能被后续低价日或高价日拉平，分析时要看多日均值。
- 成本高时，若未超过合理观察周期且质量没有明确恶化，优先保持耐心，不要频繁干预。
- 成本过低时，要预判后续成本回升。预算高于基准线时可适当降低 200-300 元；最低 300 元预算计划通常不建议再降。
- 账户通常要经历 5-10 次波动才更可能进入稳定区间。
- 排查外部原因后，若数据仍大幅波动超过 50%，进入预算控制和风险排查。

## 3. 出价、预算与起量

- 出价应围绕大盘价格调整，过高可能偏离赛道，过低可能拿不到优质流量。
- 稳定价格比频繁调价更重要。可以谨慎上调，避免持续下调。
- "高开低走" 更像旧 CPC 时代打法，不适配当前本地推 oCPM 机制；持续降价会伤害系统学习和流量获取。
- 起量的核心标志是正常出价水平下短时间内消耗突然上升，而不是全天匀速消耗小额预算。
- 爆量素材出现时，消耗速度会突然提升；优质账户往往有波动性，不一定追求平滑消耗。
- 初始预算要从低到高阶梯增加，避免一开始设置过高预算。
- 常规新计划可用 300 元左右作为基准预算；搜索或初期测试常用 300-500 元/日。
- 放量阶段建议约 20% 递增，避免单日翻倍或突然把预算从低位拉到 800-900 元。

## 4. 测新、账户矩阵与素材隔离

- 放量且保持成本/质量稳定时，可开 2-3 个账户做差异化测试。
- 账户之间按素材类型隔离：口播、混剪、情景剧等不要在同一账户中互相干扰。
- 多账户必须内部协同，严禁账户间恶性竞价或逐级抬价。
- 测新预算采用 30% 测试资金 + 70% 稳定资金模型。
- 新素材/新计划预算占比过高会冲散账户模型，影响整体 ECPM 和稳定性。
- 无报量时每周至少上新 5-10 条新素材；有爆量计划时每天 1-2 条新计划即可。
- 新计划表现好时逐步加预算并替代老计划；表现差时保持稳定，不要突然加大预算。

## 5. 计划关停与时段管理

- 最小测试周期通常为 2-3 天；不应只跑 2 小时或因单条转化差就关停。
- 暂停前要小型复盘：确认成本或质量持续不可接受、计划无挽救空间，再关闭。
- 一旦关闭，不建议再频繁重新开启；开启后也不要轻易暂停。
- 频繁开关会伤害系统学习。需要临时暂停时，优先用 "调整时段/拉空时段" 代替直接关停。
- 指定投放时段尽量连续，最低不低于 6 小时。
- 凌晨 00:00-01:00 是账户重新开跑的重要时段，建议保留预算覆盖。
- 高峰时段参考：凌晨 0-1 点、早晨 5-8 点、中午 12-13 点、下午 18-24 点。
- 若预算过早耗尽，可增加总预算覆盖后续高峰，而不是把时段切得过碎。

## 6. CTR、CVR、ECPM 联动

- CTR 过高但 CVR 过低，通常会导致成本高，可能是文案过激、承接弱或人群质量差。
- CTR 低但 CVR 高，通常量少但成本可能低；可优化文案激进度提高点击。
- CTR 与 CVR 同步上涨，是更健康的起量信号。
- ECPM 要参考账户自身历史、城市、产品、定向和行业大盘。行业均值略高可能更利于获取流量，但过高不一定好。
- 单点调整可能影响全局，因为 CTR/CVR/ECPM 会联动变化。

## 7. 素材审核与合规风险

- 个别素材被拒时，不要因为强迫症立即删除，要综合评估整条计划，避免误删优质计划。
- 涉政素材、警徽、制服、警察、消防等高风险元素必须立即下架或规避。
- 涉政内容可能连带影响账户主体及法人，应严格按广告法和平台审核口径处理。
- 计划内素材存在动态平衡，删除被拒素材可能导致其他素材被系统重新审查或拒绝。
- 后台优化建议不等于必须执行。价格调整建议可能带有平台收益导向；同质化或配比建议更值得采纳。
- 只要计划显示 "投放中" 且业务指标可接受，通常无需处理所有后台建议。

## 8. 定向与人群包

- 基础定向必须设置地域、性别、年龄，并排除明显不适配区域或人群。
- 年龄建议按 5 岁颗粒度分段；部分场景可排除低决策力人群。
- 行为兴趣优先使用系统推荐；"不限" 或过度自定义容易导致效果不佳。
- 定向包和排除包绝对不能选反，需反复确认覆盖人群。
- 已转化用户过滤建议 7-30 天或按组织账户场景控制，最长通常不超过 3 个月。
- 商品推广优先 "门店附近"，服务推广优先 "行政区域"。
- 自定义区域可能导致量级小、成本高，应谨慎使用。

## 9. 搜索广告规则

- 搜索广告承接主动需求，通投广告制造/触达需求。
- 抖音搜索流量占比参考 20-30%，通投约 70-80%。
- 搜索用户转化意愿通常高于被动浏览用户，适合高客单价、重决策品类。
- 搜索广告 CPM 通常比通投高 15-20%，但转化率可能提升 30-50%；需看真实用户成本。
- 搜索广告搭建时必须明确选择 "搜索广告" 类型，避免默认创建通投。
- 初期优先手动投放 + 稳定成本，日预算 300-500 元测试。
- 避免手动投放 + 最大转化组合导致成本失控。
- 关键词建议 200-300 个，分类覆盖品牌词、竞品词、行业词。
- 匹配方式推荐短语匹配；精确匹配量小，广泛匹配可能带来无关流量。
- 智能拓流可扩展有效关键词，通常建议保持开启。
- 搜索广告文案要用疑问句承接搜索需求；通投文案更偏制造需求。
- 搜索素材前 3-5 秒要直击用户痛点问题，可与通投素材拼接，但不建议启用动态创意。
- 搜索出价可在通投出价基础上浮约 10%。
- 搜索广告即使表现不佳，也建议保留基础预算承接精准需求。

## 10. 线索跟进与数据回传

- 客户留资后 1-2 小时内必须完成跟进，此时需求记忆和购买意愿最强。
- 周末或非工作时间只要广告在投，就要保持跟进，否则线索有效率可能明显下降。
- 单个客户可能向多家商家留资，跟进延迟会把成交机会让给竞品。
- 未及时跟进的线索可能进入二次销售池；响应延迟每增加 1 小时，响应率可能显著衰减。
- 数据回传可让系统获得正向反馈，形成投放-成交的良性循环。
- 不回传并不能可靠保护数据隐私；平台可能通过其他渠道识别交易与行为数据。

## 11. 操作错误清单

| 错误 | 后果 | 预防 |
| --- | --- | --- |
| 小数点错误，如 60.08 输成 608 | 超额消耗或巨大损失 | 数字复核、输入验证 |
| 定向包/排除包选反 | 成本和人群严重失真 | 双人复核、确认覆盖人群 |
| 文案错别字 | 法律/舆论/客户信任风险 | 三级审核、文本校对 |
| 时段规则理解反了 | 全天无效或错投 | 确认平台蓝色/勾选含义 |
| 产品与素材错配 | 数据失真、销售难跟进 | 建立素材-产品对应表 |
| Mac 特殊字符异常 | 可能导致异常消耗 | 关键步骤优先 Windows |

## 12. 卡片与创意要素

- 卡片通常显示在右下角头像区域，避免被字幕遮挡。
- 标题直接展示产品名称，尽量短。
- 配图可用公司 logo 或产品图，1-10 张均可，但建议不超过 3 张。
- 卖点要直击用户痛点和用户获益，避免自夸式表达。
- 行动号召使用深层动作指令，如 "立即预约"、"上门量房"，少用泛化的 "查看详情"。
